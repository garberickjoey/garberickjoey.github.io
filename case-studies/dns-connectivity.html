DNS & Connectivity Troubleshooting

A repeatable troubleshooting method for connectivity problems.

Layered workflow

1. Physical: link state, cabling, switch port, wireless association.

2. Local configuration: IP address, subnet mask, gateway, DNS servers.

3. DHCP: lease information, scope availability, reservations and options.

4. DNS: forward/reverse lookup, correct records, authoritative server, client cache.

5. Routing: gateway reachability, route table, VLAN path and firewall policy.

6. Application: test the actual service rather than stopping at ping.
