# Joey Garberick — IT & Network Administration Portfolio

A GitHub Pages portfolio focused on network administration, IT infrastructure, troubleshooting, and cybersecurity.

## Publish with GitHub Pages

1. Create a new GitHub repository named `joeygarberick.github.io` (or another repository you prefer).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `resume.pdf` with your actual resume filename

The project and case-study pages are intentionally written as starter material. Replace any hypothetical lab details with your actual configurations, screenshots, diagrams, and sanitized work examples.

## Recommended repository structure

```text
/
├── index.html
├── style.css
├── README.md
├── resume.pdf
├── projects/
│   ├── network-design.html
│   ├── active-directory.html
│   ├── network-security.html
│   └── disaster-recovery.html
└── case-studies/
    ├── ad-authentication.html
    ├── dns-connectivity.html
    └── application-performance.html
```

Do not publish customer names, credentials, public IPs, internal hostnames, screenshots containing PII, proprietary configurations, or other confidential MSP information.
